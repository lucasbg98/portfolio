# Portfolio: Lucas Bragança Gonçalves

Personal portfolio site, bilingual (English / Brazilian Portuguese).

- **Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4
- **Content:** all copy lives in [`src/content.ts`](src/content.ts), one object per language
- **Language toggle:** client-side, remembers the choice in `localStorage` and falls back to the browser language

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Live at **https://lucasbragancadev.vercel.app**, deployed on Vercel from the `main` branch.
